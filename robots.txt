# robots.txt Vorlage für eine Firmenwebsite, Stand August 2026
#
# Zwei Regeln tragen den ganzen Rest:
# 1. Die Sitemap-Zeile gehört rein. Ohne sie erfährt ein Crawler, der
#    deine Search Console nicht kennt, nichts von deinen Sitemaps.
# 2. Retrieval-Bots nicht blocken. Sie holen die Seite, die ein Modell
#    gerade zitieren will. Wer sie sperrt, verschwindet aus der Antwort.
#
# crawl-delay steht bewusst nicht drin: Google unterstützt es laut eigener
# Doku nicht, es ist nicht Teil von RFC 9309, und kein grosser AI-Anbieter
# dokumentiert Support. Es kostet nur Verwirrung.
#
# example.ch überall durch die eigene Domain ersetzen.

# --- Alle Crawler -----------------------------------------------------
